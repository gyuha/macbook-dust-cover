# 실행 기록 — MacBook Pro 14" M5 환기구 먼지 덮개

워크플로우 없이 직접 실행했다(스크립트 3개 규모라 서브에이전트가 더 비쌈).

## 슬라이스별 결과
- S1 `dust_cover.py` 모델링 스크립트 — ⚠ 2회 재작업: (1) 아치형 지붕·둥근 끝 (2) 핀 결합이 잘 안 맞아 평면 도브테일로 교체 (3) 출력 방향(세워서 쌓기) 기준으로 재설계: H자 탭, 원형 홀, 안쪽 탭 45° 경사. 조각 154/136×33.5×36mm
- S2 `check_cover.py` 기하 검증 — ⚠ (d)에 덩어리 수 검사, (b)에 이동 시 걸림(잠금) 검사, (c)에 터널 막힘 검사 추가. stdout 버퍼를 flush하지 않으면 `SystemExit` 시 출력이 사라져서 flush를 추가함. 잘못된 파라미터(GAP=20, OVERLAP=30)로 FAIL이 실제로 나는 것도 확인함
- S3 `README.md` 출력 안내 — ✅ 계획대로 (파라미터 8개 모두 `dust_cover.py`에 존재 확인)

## DoD baseline → after
- DoD 1 (`dust_cover.py` 실행, STL 2개): 없음 → 종료 코드 0, STL 2개 생성 (순방향 검사, 곡면 버전으로 재실행)
- DoD 2 (`check_cover.py`): 스크립트 없음 → PASS 4줄, FAIL 0줄, 종료 코드 0 (순방향 검사, 곡면 버전으로 재실행)
- 사용자 확인(UAT): 미실시. PLA 출력 후 맥북에 얹어 봐야 판정 가능

## 판단과 변경
- 지붕 두께 4mm(곡면 두께), 상부 리브 없음: 출력 시 지붕 윗면을 베드에 대고 뒤집어 서포트 없이 뽑기 위해서
- Blender로 `preview-tab.png`(H자 탭과 원형 홀), `preview-stand.png`(세워서 출력하는 모습), `preview-seam.png`(이음선에서 V자로 맞닿는 다리) 렌더링
- 받침 블록은 없앴다. 다리 두 장 + 가로대(4mm, 원형 홀 지름 8)의 H자이고, 다리에는 지름 7 원형 창. 안쪽 탭은 길이 24mm 삼각 다리(앞쪽 45°). 지붕 윗면과 슬릿 구간은 그대로
- 서포트 검사: `check_cover.py` (a)가 쌓는 방향 기준 오버행 45° 초과 면을 이웃끼리 묶어 최대 덩어리 면적 ≤45mm²를 요구한다(원형 홀 꼭대기 호는 24mm²). 안쪽 탭 경사를 뺀 모델에서 173mm²로 FAIL이 나는 것을 확인함
- 지붕 지지는 조각마다 끝 탭 2곳(다리 + 받침 블록)뿐이고, 탭 사이 구간에는 다리가 없어 슬릿 구간이 열려 있음. 탭 사이 최대 약 100mm 지붕이 떠 있어 처짐은 출력 후 확인 필요
- 이음은 평면 도브테일(장부 19mm, 뿌리 10mm → 끝 16mm, 한쪽 여유 0.12mm)이다. 이 19mm가 계획 DoD의 겹침 15~20mm를 충족한다(계획 변경 없음). 당김 방향 X 유격은 약 0.5mm로 계산됨
- 핀 결합은 제거함. 이유: 잠금이 약해 길이 방향으로 벌어졌다는 사용자 피드백

## 알려진 위험
- 덮개 길이 272mm는 사진 추정이다. 힌지 띠 실제 길이, 왼쪽 끝 단차, 오른쪽 케이블, 뒤쪽 물체 간격은 실물로 확인 전
- PLA 내열(약 55~60°C)은 부하 상태에서 확인 전

## 요구 추가 (UAT 전)
- 4회차: 사용자가 "앞 방향(H자·원형 홀·세워서 출력)은 원하던 대로"라고 확인한 뒤 추가 요청 — (1) 가운데 이음선 쪽 안쪽 탭의 원형 홀 제거, (2) 안쪽 탭을 반대쪽 조각과 맞붙게(가운데가 떠 보이지 않게). 수정함: 안쪽 탭은 홀 없음, 두 안쪽 탭의 수직 모서리를 이음선까지 늘려 0.12mm 틈으로 맞닿게 함. 다리와 겹치지 않도록 도브테일을 가늘게(뿌리 10, 끝 반폭 8.1) 하고 길이 19, 유격 0.12로 잠금 유지(±1mm 이동 시 6.9mm³ 걸림)

## Failed attempts
- 1회차: 사용자가 "모양이 너무 네모반듯하다, 상단을 곡선으로" 피드백 / 수정함: 지붕 단면 아치형(`ROOF_RISE`=6), 바깥 끝 모서리 둥글게(`CORNER_R`=8). 해석은 "단면 아치 + 평면 모서리"로 했고 사용자에게 확인 필요
- 2회차: 곡면+핀 결합 버전을 본 사용자가 "핀 결합이 잘 연결되지 않는다, 도브테일로" / "받침 블록 중간을 뚫어 옆으로 공기가 흐르게" 요청 / 수정함: 평면 도브테일 조인트(장부 길이 18mm = 계획 DoD의 겹침 15~20mm 유지)와 블록·다리 환기창
- 3회차: 사용자가 "지금 방식은 FDM으로 뽑기 어렵다. 옆면 기준으로 위로 적층하고, 연결부는 H자(옆에서 볼 때 |ㅁ|를 단순화), 홀은 원형으로 서포트 없이" 요청 / 수정함: 끝 탭을 H자(다리 두 장 + 가로대)로 단순화, 다리 창과 가로대 홀을 원형으로, 안쪽 탭 앞쪽 45° 경사, 바깥 끝 모서리 곡선을 45°에서 시작하게 변경. 원인: 계획에 출력 방향 제약이 없었음
- 출력 방향은 "바깥 둥근 끝면을 베드에 세워서(A)"로 해석했다. 이후 사용자가 "해당 부분은 원하던 대로 되었다"고 확인함
