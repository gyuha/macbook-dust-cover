# 실행 기록 — 가운데 이음의 M3 나사를 스냅 후크로 교체

실행 방식: 슬라이스 3개가 직렬이고 규모가 작아 워크플로우 없이 메인 세션에서 직접 처리했다.

## 슬라이스 결과
- S1 `dust_cover.py` 나사 제거 + 혀 16mm + 턱·홈·뿌리 라운드 — ⚠ 실행 후 피드백으로 혀 아랫면 수평화·네모 턱·바깥 판 모따기로 수정 (왼쪽 가로대는 복원)
- S2 `check_cover.py` (b) 경로 검사 삭제, (e) 후크 검사로 교체, 틀린 값 FAIL 확인 — ⚠ 턱 돌출 0은 형상이 퇴화해 0.01로 시험
- S3 README·`render_images.py` 주석·FreeCAD 캡처 이미지 6장 갱신 — ✅ 계획대로

## 계획과 달라진 점
- **왼쪽 가로대 제거(S1)**: LAP를 16으로 늘리자 왼쪽 조각이 두 덩어리가 됐다(`check_cover.py` (d) FAIL, 떨어진 덩어리 828mm³, x 120~136, z 1~5). 안쪽 탭 가로대는 `leg_prism` 때문에 이음선에서 약 12~16mm까지만 있다. 그런데 안쪽 겹을 16.05mm 비우면 이를 붙잡던 안쪽 겹이 모두 사라진다. 그래서 겹침 구간의 왼쪽 노치를 안쪽 겹 두 장에서 Y 전체 폭(fa~bb)으로 넓혔다. 결과적으로 왼쪽 조각의 안쪽 가로대가 없어졌다.
  - 이음선 가로대 홀은 오른쪽 반원 홈만 남는다.
  - 패드 위치는 4곳에서 3곳으로 줄었다. README에 반영했다.
- **틀린 값 시험(S2)**: `HOOK_H = 0`이면 턱 다각형이 퇴화한다. 그래서 임시 디렉터리 사본에서 0.01로 돌렸다. 결과는 `FAIL (e)` (걸림 0.000, 턱 0.01)이다. 방향별로 보면 +X 0.000, -Z 0.000, +Z 33.7이다. +Z는 턱이 없어도 혀 위쪽이 왼쪽 지붕에 닿아 막힌다. 그러므로 당기기(+X)와 아래(-Z)는 후크만이 막는다.
- 실제 모델의 방향별 걸림: +X 2.475, +Z 35.024, -Z 1.324 mm³.

## DoD 기준값 → 실행 후
1. `$F dust_cover.py` 종료 코드: 0 → 0 (회귀 가드, 원래부터 통과)
2. PASS/FAIL 개수: 5/0 (나사) → 5/0 (`PASS (e) 후크: … 가장 약한 걸림 1.324mm3, 혀 L=16.05 t=2.35 턱 0.60 → 변형률 0.82%`). `grep -c 후크`: 0 → 1
3. 틀린 값 FAIL: 해당 없음 → `FAIL (e)` 확인 (0.01로 시험, 위 참고)
4. `나사|M3|SCREW|PIN_Z|올려 끼` 개수: README 19, dust_cover 10, check_cover 3, render_images 1 → 모두 0
5. README 후크 설명: 나사 설명 → 이음 절, 이동 차단 표, 치수 표, 검증 표, 출력·조립 절차, 파라미터 표, 알려진 한계 갱신. README에 나오는 `` `대문자` `` 파라미터 이름은 모두 `dust_cover.py`에 있다(검사 결과 누락 0).
6. 이미지 6장: 나사 구멍 있음 → 2026-10-28 18:55에 다시 렌더링. 턱(0.6mm)은 이 배율에서 보이지 않는다.

## 남은 위험
- 혀 뿌리 층간 강도는 계산값(0.82%)일 뿐이고 실물로 확인하지 않았다.
- 오른쪽 조각 높이가 144mm에서 152mm로 늘었다. 출력 한계 250 이내다.

## 추가 수정 (2026-10-28, 실행 후 사용자 피드백)
- 사용자가 오른쪽 조각 캡처 이미지에 표시하며 두 가지를 요청했다.
  1. 혀 아랫면을 빨간 선 높이(혀 끝 바닥)에서 수평으로 자른다.
  2. 후크를 네모 턱으로 바꾸고, 바깥쪽(두께 방향)으로 튀어나와 걸리게 한다.
- 반영한 내용:
  - `LUG_Z0` = 혀 끝에서 45° 선의 높이(≈ 5.08)를 계산값으로 둔다. 혀 박스는 `LUG_Z0`부터 시작하고, 혀에는 `leg_prism` 클립을 쓰지 않는다.
  - 왼쪽 노치는 `LUG_Z0 - SEAM_CLEAR` 위로만 비운다. 그래서 S1에서 지웠던 왼쪽 안쪽 겹·가로대·이음선 반원 홀·패드 4곳이 돌아왔다(이음선 다리 부피 L 46.5 → 47.2, 원래 값과 같음).
  - 턱에서 45° 경사를 없애고 네모로 만들었다. 경사는 왼쪽 바깥 판 끝 안쪽 모서리의 45° 모따기 `HOOK_LEAD` = 1.0으로 옮겼다. 이 모따기가 S1의 혀 뿌리 비움 자리(`root_fillet(cut=True)`)를 포함하므로 그 코드는 지웠다.
- 측정:
  - `check_cover.py` PASS 5 / FAIL 0. 가장 약한 걸림은 2.475mm³이다.
  - 방향별 걸림: +X 2.475, +Z 35.193, -Z 35.007mm³.
  - 혀 끝 단면 YMin −3.55(네모 턱). 모따기 자리의 재료는 0.
  - 턱 0.01 시험: `FAIL (e)`, +X 0.000. -Z는 이제 왼쪽 안쪽 겹이 받쳐 33.5이므로, 후크에만 기대는 방향은 당기기(+X) 하나다.
- README(이음 절, 차단 표, 치수 표, 검증 표, 패드 위치, 파라미터 표)와 이미지 6장을 갱신했다. 금지어 개수는 파일마다 0이다.
