# MacBook Pro 14" M5 환기구 먼지 덮개

세로로 세운 맥북의 힌지 환기구 위에 얹는 지붕형 덮개입니다. 지붕은 단면이 아치형이라 가장자리에서 12mm, 가운데에서 18mm 떠 있고, 좌우·앞뒤가 열려 있어 공기는 빠지고 위에서 떨어지는 먼지만 막습니다.

- **H자 탭:** 맥북 윗면을 잡는 끝 탭은 옆에서 보면 H자입니다. 다리 두 장(기둥)을 얇은 가로대(4mm)로 잇습니다. 바깥 탭은 다리가 깊고(`preview-tab.png`), 안쪽 탭은 45°로 깎인 삼각 다리입니다.
- **가운데 이음선:** 두 조각의 안쪽 탭 삼각 다리가 이음선에서 수직 모서리끼리 0.12mm 틈으로 맞닿아 V자로 이어집니다(`preview-seam.png`). 가운데가 떠 보이지 않습니다. 안쪽 탭에는 홀을 뚫지 않았습니다.
- **원형 홀:** 바깥 탭의 다리에 원형 창(지름 7mm, 앞뒤로 공기 통과), 가로대에 원형 홀(지름 8mm, 환기구 쪽에서 위로 공기 통과)을 뚫었습니다. 원형이라 서포트가 필요 없습니다.
- **도브테일 이음:** 왼쪽 조각의 끝이 넓은 장부(길이 19mm, 뿌리 10mm에서 끝 16mm)를 오른쪽 조각의 홈에 끼웁니다. 길이 방향으로 당겨도 빠지지 않습니다.
- **출력 방향:** 바깥 둥근 끝면을 베드에 대고 **세워서** 출력합니다(`preview-stand.png`). 서포트가 필요 없도록 설계했습니다.

흐름: 파라미터 수정 → `dust_cover.py` 실행 → `check_cover.py` 검증 → Bambu Studio 출력 → 맥북에 얹어 확인

## 파일
- `dust_cover.py`: 모델 생성. `cover-left.stl`, `cover-right.stl`을 만든다.
- `check_cover.py`: 크기와 서포트 없이 쌓이는지(오버행 45°), 도브테일 맞물림과 잠금, 지붕 간격과 원형 홀, 닫힌 솔리드를 검사한다. `PASS` 4줄이면 정상이다.
- 실행: `/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd dust_cover.py` (검증은 `check_cover.py`)

## Bambu Studio 출력
1. 두 STL을 모두 불러온다. 왼쪽 조각은 155×33.5×36mm, 오른쪽 조각은 136×33.5×36mm이다.
2. **왼쪽 조각:** 바깥 둥근 끝(X=0, 도브테일 장부가 없는 쪽)이 아래로 가도록 **세운다**. 도브테일 장부가 맨 위가 된다. 높이 154mm.
3. **오른쪽 조각:** 바깥 둥근 끝(도브테일 홈이 없는 쪽)이 아래로 가도록 **세운다**. 홈이 맨 위로 열린다. 높이 136mm.
4. 서포트는 끈다. 베드에 닿는 면이 작으니 브림을 켜는 것을 권한다. PLA 기준 레이어 0.2mm, 벽 3줄, 채움 15~20%.
5. 출력 후 오른쪽 조각을 위에서 내려 왼쪽 장부를 홈에 끼운다. 접착은 필요 없다.
6. 처음 끼울 때 뻑뻑하면 장부 옆면을 사포로 살짝 다듬고, 헐거우면 `DT_CLEAR`를 줄여 다시 출력한다.

## 패드 부착
가로대 아랫면(조각마다 2곳, 총 4곳)에 두께 1mm 펠트나 TPU 패드를 붙인다. 알루미늄 윗면 스크래치를 막는 용도이고, 지붕 간격 12mm에는 이 1mm가 이미 포함되어 있다(`PAD_T`).

## 맞지 않을 때 고칠 파라미터 (`dust_cover.py` 맨 위)
| 증상 | 파라미터 |
|---|---|
| 힌지 띠보다 짧거나 길다 | `TOTAL_LEN` (현재 272, 띠 길이는 사진 추정이라 틀릴 수 있다) |
| 다리가 헐겁거나 꽉 낀다 | `CLEAR` (0.6) |
| 슬릿을 가리거나 다리가 걸린다 | `SKIRT_DEPTH` (바깥 탭 다리 14), `INNER_DEPTH` (안쪽 탭 6), `TAB` (15) |
| 열이 고인다 | `GAP` (12, 10~15 범위), `ROOF_RISE` (6, 클수록 가운데가 높아 공기 통로가 넓다) |
| 더 둥글게/덜 둥글게 | `ROOF_RISE` (0이면 평평한 지붕), `CORNER_R` (8, 바깥 끝 모서리) |
| 도브테일이 안 들어가거나 헐겁다 | `DT_CLEAR` (0.12, 꽉 끼면 0.15, 헐거우면 0.1). 맞물림 길이는 `DT_LEN` (19, 15~20 범위). `DT_ROOT`+`DT_FLARE`로 끝 폭을 키우면 다리와 겹치니 끝 반폭 8.1mm 이하로 유지 |
| 공기가 더 잘 흘러야 한다 | `BAR_HOLE_D`(가로대 홀 8), `SKIRT_HOLE_D`(다리 창 7), `SKIRT_HOLE_Z`(다리 창 높이 10) |

수정 후 두 스크립트를 다시 실행한다. 뒤쪽 은색 물체와의 간격, 오른쪽 케이블, 왼쪽 끝 단차는 알 수 없는 값이므로 맞춰 보며 확인한다.

## PLA 내열
지붕 아래 배기 공기가 PLA 연화 온도(약 55~60°C)에 가까워질 수 있다. 부하를 건 뒤 지붕 안쪽이 무르거나 휘면 PETG로 다시 출력한다.
